# Code of conduct

Plainread exists to help people who are often treated badly by complicated systems.
We expect everyone in this project to be patient, respectful and kind — especially
to people who are new, who are not native English speakers, or who are not
technical.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report unacceptable behaviour privately through
[GitHub security advisories](https://github.com/lobojoel2003/Plainread/security/advisories/new)
or to the maintainer's GitHub profile.
